# Web名刺 要件

- 型: コンパクト名刺（1スクロール寄りの交流用名刺）
- 主役セクション: 肩書き + キャッチコピー（アイコン画像を添える）
- PC対応: する（カード幅 480px 前後で中央寄せ。スマホ表示を最優先）
- 動きの量: 少し（入場フェードとホバーのみ。`prefers-reduced-motion` で停止）
- セクション順: Profile → About → Skills → Highlights → Links
- 名前: （氏名）※漢字表記・本人が記入 ／ ローマ字 （Romaji）
- 肩書き: フルスタックエンジニア / 大阪情報専門学校
- キャッチコピー: 「バックエンドもフロントも、まるごと作ります。」（鉤括弧つきで大きく組む）
- 写真: 1枚 `assets/avatar.png`（イラストアイコン、円形に切り抜き。カルーセルなし。未配置の間は頭文字アバターを表示）
- 自己紹介:
  大阪情報専門学校に在籍しながら、医療系システムの基盤開発に携わっているフルスタックエンジニアです。
  JavaやPython、Goでのバックエンド開発から、TypeScript・Astroを使ったフロントエンドまで幅広く手を動かしています。
  個人開発とOSSへのコントリビュートが好きで、いまはOSSの開発に力を入れています。
- 技術スタック: Java / Spring Boot / Python / Flask / Go / Gin / JavaScript / TypeScript / Astro / Vite / PostgreSQL / IIS / Linux

  3. 業務 — 医療系システムの開発：Python・TypeScript でバックエンド／フロントエンドの両方を担当

- デザイン:
  - 方向性: 名刺（meishi）の作法 ＋ おもちゃのように弾む動き（参考: https://yui540.com/）
  - 主役: NFCをタップして開かれる前提を活かし、アイコンが吹き出しで話しかける
  - 雰囲気: ポップ・親しみやすい。丸ゴシックがある端末ではやわらかい字面になる
  - 配色: ダーク / ライト両対応（端末設定に自動追従、`color-scheme: light dark`）
  - 色: 紫ひとつだけ（ライト `#6d28d9` / ダーク `#b79cff`）。強調は色ではなく文字の大きさと余白でつくる
  - 地: 紫のドット（20px間隔）で紙のような質感を出す
  - 組版:
    - 見出しは字間を空けた欧文（21px / `0.34em`）に、小さな和文（10.5px / `0.24em`）を添えて中央揃え
    - 名前 46px → キャッチ 21px → 本文 14〜15px の3段構え
    - ローマ字は `0.3em` の字間で名前に添える
    - 和文は `palt` で字詰め、`word-break: auto-phrase` で文節折り返し
  - 角丸: カード 26px / タイル 18px / ボタン 16px / アイコン 26px
  - 動き:
    - 登場（約1.1秒で終わる）: カード → アイコンが回りながら出る → 名前が1文字ずつ弾む → 吹き出し
    - アイコンをタップするとセリフが変わり、アイコンが揺れる
    - スクロールで各ブロックが弾んで現れる（IntersectionObserver）
    - `prefers-reduced-motion` ではすべて静止し、内容は最初から見える
  - セクション構成: あいさつ → 名前 → キャッチ → 自己紹介 → PROFILE → WORKS → LINKS
  - 前提: スマホでNFCタッチして開く想定 → 縦1カラム、指で押しやすいリンクボタン
  - 準拠: `.claude/skills/design-skills`（frontend-design / Web Interface Guidelines）
